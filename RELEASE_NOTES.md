# SleepManager 0.8.1

SleepManager 0.8.1 is a compatibility update for **RAOfflineProxy Automation API v3**.

## What's Fixed

- Restored compatibility with RAOfflineProxy 3.1.0-alpha1, which reports Automation API v3.
- Retained compatibility with API v1 and v2.
- Existing cache-queue and pending RetroAchievements award protection, sleep/wake ordering and restore ownership remain unchanged.

## Compatibility

- SleepManager **0.8.1 / versionCode 571**
- SleepManager Helper **1.1.7 / versionCode 1121** (unchanged)
- Android **9 / API 28 or newer**
- Existing settings are retained when updating an official signed build.

## Installation and Updating

Install **SleepManager-0.8.1.apk** over your existing official version, or update through **About → Updates**. No Helper update is required if you already have 1.1.7.

> [!WARNING]
> **AYANEO / KONKR devices with DuraSpeed:** disable DuraSpeed in Android Settings. Battery usage set to Unrestricted does not override DuraSpeed's background restrictions.
