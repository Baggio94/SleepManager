# SleepManager 0.7.4-beta1 — combined test build

This **test APK** brings together:
- PR #46: smoother Home UI by refreshing expensive UI metadata off the main thread.
- PR #50: state-aware Key Mapper 4.7+ integration, opt-in and off by default.

Android package `com.med.sleepmanager`, version code **569**. Compatible with the
existing stable signing key so this signed beta can be installed as an update
over 0.7.3 (567) or 0.7.4 UI preview (568). Helper remains **1.1.7 / 1121**.
No release tag, no stable publication, and no change to the main branch.

Manual test on AYN Thor:
1. Update the signed beta APK and open SleepManager. Check smooth Home scrolling
   at 120Hz with the 3-second status refresh active.
2. Install Key Mapper **4.7.0+**, open it to synchronize paused/active state.
   Opt in to Key Mapper under SleepManager integrations.
3. When mappings start active: sleep the Thor (power button and lid); mappings
   should pause, then resume on a real wake.
4. When mappings were manually paused: SleepManager must leave them paused.
5. Test missed initial state, reboot, service restart, quick sleep/wake, and
   disabling SleepManager while a cycle is active.
6. Ensure the other integrations and the Activity Log still work.

Only promote to stable after physical-device verification and CI green.
