Android sleep & wake manager

Let your handheld actually sleep.

SleepManager helps reduce unnecessary standby activity on Android gaming handhelds, phones and tablets. It can manage Wi-Fi, Bluetooth, Syncthing-Fork, BasicSync, Tailscale and other integrations while the device sleeps, then restore only the state it changed when you wake it.

What SleepManager does

Choose what should be managed during sleep. SleepManager keeps track of the state it actually changed so it can restore things conservatively after wake.

Wi-Fi & Bluetooth

Temporarily disable radios during sleep and restore them only when SleepManager changed them.

Syncthing-Fork

Stop Syncthing during sleep and return control to its normal FOLLOW behavior after wake and network recovery.

BasicSync

State-aware sleep and wake handling with BasicSync 3.18+ remote-control and state broadcasts.

Tailscale & JamesDSP

Manage supported integrations automatically as part of the same sleep and wake cycle.

Battery statistics

Track sleep duration, drain per hour, deep-sleep percentage, recent sessions and standby estimates.

Conditions & delays

Use grace periods, custom delays, battery level, charging state, Battery Saver and time windows.

How it works

SleepManager reacts to real sleep and wake transitions instead of forcing one permanent Android configuration. It records what it changed during a sleep cycle so wake restoration stays conservative.

1. Screen turns off

After your selected grace period or delay, SleepManager checks the enabled conditions before changing anything.

2. Sleep actions run

Selected radios and supported background integrations can be paused, stopped or disconnected to reduce unnecessary standby activity.

3. Wake restores state

SleepManager restores only the states it owns, helping avoid overwriting choices that were already made by you or another app.

Frequently asked questions

The short answers to the most common installation and compatibility questions.

Does SleepManager require root, Shizuku or ADB?

No. Normal use does not require root, Shizuku or ADB. Some features use the optional signed SleepManager Helper or Android permissions exposed by the system.

Which Android devices can use it?

SleepManager supports Android 9 / API 28 or newer and is designed mainly for gaming handhelds from brands such as AYN, Retroid, ANBERNIC, AYANEO and KONKR. It can also run on regular Android phones and tablets.

Will SleepManager always turn Wi-Fi or Bluetooth back on?

No. It tracks whether it actually changed a state during the sleep cycle and restores only what it owns. If Wi-Fi was already off before sleep, SleepManager does not turn it on just because the device wakes.

What can I check if standby drain is still high?

Open Activity to review the latest sleep and wake actions, check Background Reliability under About, and use Copy log when reporting an issue. Battery drain can also come from firmware, other apps, radios or services that SleepManager is not configured to manage.

Need more detail? The GitHub README contains the full feature, permissions, integration and troubleshooting documentation.

Why SleepManager?

Android handhelds can sit in standby much longer than a typical phone. Background radios, sync tools and network services may keep doing work even when you are not using the device. SleepManager gives you one place to quiet selected activity during sleep and restore it when the device wakes.
