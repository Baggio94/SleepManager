Better standby for Android handhelds.

SleepManager is a free, open-source Android utility that manages what happens when your handheld goes to sleep. It can quiet radios and background apps, automate save syncs, protect clamshell devices from false wakes, and restore only the states it actually changed.

I started it after getting tired of unnecessary standby drain on my own Android handhelds. What began as a small sleep helper has grown into a more complete sleep/wake manager, while staying focused on one thing: letting a device sit unused without doing more work than it needs to.

What it actually does

SleepManager reacts to sleep and wake transitions instead of forcing one permanent Android configuration. It keeps track of the changes it owns, so wake restoration stays conservative.

Radios and Battery Saver

Turn Wi-Fi or Bluetooth off while sleeping, and enable Battery Saver when appropriate. Previous states are restored only when SleepManager changed them.

Save-sync automation

Run supported sync clients before sleep, after wake, or periodically during long sleep sessions. Completion-aware sync is available with BasicSync 3.19+.

Clamshell protection

Handle closed-lid false wakes and optional dock, power-button and Charging Separation behavior on compatible handhelds such as the AYN Thor.

Battery stats

Track sleep duration, drain rate, measured mAh when available, deep-sleep percentage, recent sessions and estimated standby time.

Conditions and delays

Use grace periods, longer custom delays, battery level, charging state, Battery Saver state and time windows to decide when sleep actions should run.

Activity and diagnostics

See what SleepManager did during recent cycles and generate detailed diagnostics when something needs troubleshooting.

Current app integrations: BasicSync, Syncthing-Fork, Tailscale, JamesDSP Manager and RootlessJamesDSP.

Latest stable release

0.7.0

Version 0.7 is mainly about reliability. A large part of the sleep/wake engine was cleaned up and split into smaller components, with tighter cycle handling and better recovery around false wakes and restores.

Read the full release notes ↗
  • Diagnostics 2.0 Optional advanced diagnostics can keep useful troubleshooting information across multiple sleep/wake cycles while staying off by default.
  • More reliable sleep/wake ownership Closed-lid false wakes preserve the original cycle and pending restores until a real wake happens.
  • Battery Saver is power-aware SleepManager avoids enabling it unnecessarily while plugged in, and can still react if external power is removed during sleep.
  • Helper 1.1.2 Wi-Fi and Bluetooth restore now use stronger cycle-aware communication and protection against delayed or stale responses.

Setup

The basic setup is intentionally short. More advanced sync and clamshell options can be added later.

Install the APK

Download the latest signed SleepManager APK from GitHub Releases and install it normally.

Add the Helper if you need it

The optional signed Helper is required for Wi-Fi and Bluetooth control. It has no launcher icon or separate interface.

Choose what SleepManager owns

Enable the controls and integrations you want, finish the permission checks, then verify the next sleep cycle in Activity.

FAQ

Does SleepManager require root, Shizuku or ADB?

No. Normal use does not require any of them. Wi-Fi and Bluetooth control use the optional signed SleepManager Helper.

Which devices does it support?

Android 9 / API 28 or newer. SleepManager is mainly built for Android gaming handhelds from brands such as AYN, Retroid, ANBERNIC, AYANEO and KONKR, but it also works on regular phones and tablets.

Will it turn Wi-Fi or Bluetooth back on every time?

No. SleepManager tracks whether it actually changed the state during that cycle. If Wi-Fi was already off before sleep, it does not turn it on just because the device wakes.

What should I send with a bug report?

Check the Activity page first. If the problem is hard to reproduce, enable Advanced Diagnostics, reproduce it, then use Copy log. Diagnostics 2.0 can preserve useful context across multiple cycles.
